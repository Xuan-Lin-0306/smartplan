# SmartPlan｜智慧任務規劃助手

> 透過 Vibe Coding 製作的互動式時間管理網頁，協助使用者依照重要程度與截止日期安排待辦事項。

**網站連結：** https://xuan-lin-0306.github.io/smartplan/  
**GitHub 專案：** https://github.com/Xuan-Lin-0306/smartplan

## 一、作品介紹與設計動機

大學生經常需要同時處理課堂作業、考試、報告、專題研究及生活中的待辦事項。當任務增加時，容易因為沒有明確的優先順序而不知道該先做哪一件，甚至拖延到截止日期前才開始處理。

因此，我希望設計 **SmartPlan 智慧任務規劃助手**，讓使用者輸入任務名稱、截止日期、重要程度及預估完成時間後，由系統自動依照規則分類任務，並透過艾森豪矩陣（Eisenhower Matrix）、任務清單與進度統計，協助使用者掌握時間與完成狀況。

### 2.2 功能需求

| 功能 | 說明 |
| --- | --- |
| 新增任務 | 填寫任務名稱、分類、重要程度、截止日期及預估時間 |
| 編輯任務 | 修改已建立任務的內容 |
| 刪除任務 | 經確認後移除指定任務 |
| 完成狀態 | 勾選或取消勾選已完成任務 |
| 自動四象限分類 | 依重要程度及距離截止日期的天數自動分類 |
| 優先排序 | 未完成任務優先，接著依象限與截止日期排序 |
| 截止提醒 | 顯示已逾期、今天截止、明天截止或剩餘天數 |
| 搜尋與篩選 | 依任務名稱搜尋；依狀態、緊急待辦或任務分類篩選 |
| 進度統計 | 顯示全部任務、待完成、緊急待辦、完成率與進度條 |
| 資料保存 | 使用 localStorage 保留同一瀏覽器中的任務資料 |
| 響應式排版 | 依螢幕尺寸調整網頁布局 |

### 2.3 四象限分類規則

使用者自行選擇任務是否「重要」；系統根據截止日期判斷是否「緊急」：**距離截止日期 3 天內（包含當天與已逾期）為緊急**。

| 象限 | 條件 | 建議處理方式 |
| --- | --- | --- |
| 第一象限：重要且緊急 | 重要、距截止日 ≤ 3 天 | 優先完成 |
| 第二象限：重要但不緊急 | 重要、距截止日 > 3 天 | 提前規劃 |
| 第三象限：不重要但緊急 | 不重要、距截止日 ≤ 3 天 | 適當安排處理 |
| 第四象限：不重要且不緊急 | 不重要、距截止日 > 3 天 | 有空再處理 |

已完成的任務仍保留在清單中，但不列入四象限的**未完成待辦**展示。這套分類是事先設計的規則判斷，並非串接生成式 AI 模型。

### 2.4 操作流程

1. 開啟 SmartPlan 網頁。
2. 輸入任務名稱、分類、重要程度、截止日期及預估時間，點選「新增任務」。
3. 系統將任務加入清單，並自動歸入四象限。
4. 使用搜尋與篩選功能，查看需要處理的任務。
5. 可編輯、刪除或勾選完成任務；統計與進度條同步更新。
6. 重新整理網頁後，已儲存的任務仍可在相同瀏覽器中查看。

### 2.5 介面規劃

- **首頁總覽**：任務總數、待完成數、緊急待辦數與完成率。
- **新增／編輯區**：任務輸入表單。
- **任務清單**：搜尋、篩選、編輯、刪除與完成勾選。
- **四象限矩陣**：視覺化呈現尚未完成的任務。
- **進度區**：完成進度條與統計文字。

整體採繁體中文、簡約紫色系介面，兼顧資訊清楚與操作便利。

### 2.6 技術與限制

本作品為純前端網頁，HTML、CSS 與 JavaScript 全部寫在 `index.html`，無須後端伺服器或外部資料庫。任務資料保存在使用者目前瀏覽器的 localStorage，**不會跨裝置同步**；若清除瀏覽器網站資料，也可能失去任務紀錄。

## 三、Vibe Coding 開發紀錄

本次使用自然語言向 AI 說明想法，透過對話討論需求，再由 AI 協助產生程式碼與整理單一網頁檔案。

| 階段 | 與 AI 的互動及成果 |
| --- | --- |
| 1. 主題發想 | 討論適合課堂作業的互動式 Web App，選擇「智慧任務規劃助手」。 |
| 2. 規格討論 | 確定任務新增、四象限分類、進度追蹤、搜尋篩選與資料保存等需求。 |
| 3. 規則釐清 | 針對「不重要但緊急」的意思與例子向 AI 提問，確認保留原本的自動分類規則。 |
| 4. AI 協助實作 | 請 AI 依規格產生 HTML、CSS、JavaScript，整合成單一 `index.html`。 |
| 5. 發布流程 | 依照 AI 的步驟說明，建立 GitHub 儲存庫、上傳網頁並設定 GitHub Pages。 |
| 6. 文件整理 | 根據實際網頁功能整理 README 規格書與開發過程。 |

**開發提示詞範例（本次實際提出的需求）：**

> 我決定做智慧任務規劃助手。請先幫我完成作業步驟一的完整規格書，再依照規格製作可以實際操作的單一 index.html 網頁。

**關於測試與修改：** 本次作業透過與 ChatGPT 對話的方式進行 Vibe Coding。首先，我向 AI 提出智慧任務規劃助手的構想，並討論系統需要具備的功能，包括任務新增、四象限自動分類、進度追蹤及資料保存等。接著，由 AI 協助整理系統規格書，並根據規格產生 HTML、CSS 與 JavaScript 程式碼，整合成單一 index.html 檔案。最後，將網頁上傳至 GitHub，並透過 GitHub Pages 公開作品。透過這次實作，我學習到如何將自己的想法轉換成具體的功能需求，以及如何利用 AI 協助完成網頁開發與部署。
